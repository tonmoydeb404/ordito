# Pricing — Ordito

Ordito is free and open source. There are no paid tiers, no accounts, and no cloud services.

## Free
- Price: $0 — no paid tiers, no subscriptions, no in-app purchases
- Platforms: macOS and Windows
- License: MIT (open source)
- Source code: <!-- @brand:repository -->https://github.com/tonmoydeb404/ordito-new<!-- /@brand:repository -->

### Included features
- Run saved shell commands from the system tray (macOS menu bar or Windows tray) or the panel
- Organize commands into named groups with instant search (Command/Control K)
- Schedule recurring runs with cron expressions, plus one-time runs
- Full run history: status, start time, duration, exit code, and captured output
- Local execution and local SQLite storage — no accounts, no cloud sync, no telemetry

### Limits
- Desktop only: macOS and Windows (no mobile app, no web app, no Linux desktop builds)
- Commands run on your local machine only (no hosted or remote execution)
